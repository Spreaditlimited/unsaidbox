Customer insights / exports / form reporting — local implementation, not deployed.

Database
Seven additive tables were manually created by the owner. Prisma schema has
been updated; do not run migrations blindly against the existing manually
managed migration history.

Export processing
New jobs get an immediate Next.js after() attempt. Durable database records
survive process termination. One global lease limits export preparation to
one worker; queries are in batches of 100 records. Three attempts maximum.
Files use Cloudinary authenticated RAW storage in unsaidbox/exports.
Downloads proxy through the authenticated application; signed provider URLs
are never returned to the browser. Files expire after 24 hours.
Private analysis includes new and existing owner responses without a separate
sender opt-in. Sharing exports still require public-sharing permission.
Spam messages, blocked forms and private follow-up bodies remain excluded.
Historical ResponseExportPermission rows are retained but no longer gate
analysis exports; no database migration or consent backfill is needed.
Download access rechecks owner, plan, permission fingerprint, account status,
expiry and revocation, then verifies file size and SHA-256 before returning bytes.

Before production release:
- Configure UNSAIDBOX_EXPORT_WORKER_SECRET as a private random secret >=32 chars.
- Schedule POST /api/internal/export-worker with Bearer authorization using a
  trusted scheduler every five minutes. Do not embed the token in a URL.
- The scheduled worker is mandatory for automatic queue recovery and physical
  deletion of expired files. Without it only immediate attempts/manual retries
  run, although application download access still expires.
- Never activate a production schedule before the code has been deployed.
- Verify Cloudinary raw-file size limits for the existing account; application
  generation is bounded to 25 MB and 180 seconds. Provider limits may be lower.
- Set maxDuration=300 for export page/actions and worker routes (already in code).
- No public CSV URLs, private reply exports, or retroactive consent grants.
